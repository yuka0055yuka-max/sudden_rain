## 起動方法（GitHub Pages）

こちらで公開してます →https://yuka0055yuka-max.github.io/sudden_rain/

1. このリポジトリを `main` ブランチに push  
2. GitHub Pages を `main` の `/` ルートで有効化  
3. `https://ユーザー名.github.io/幻想都市/` にアクセス  
4. PWAとしてホーム画面に追加可能（スマホ推奨）

---

## 🔧 カスタマイズ例

- `index.html` の `init()` に通行人や傘を追加  
- `drawTrafficLights()` にカウントダウン表示を追加  
- `manifest.json` に `"display": "fullscreen"` を指定して没入都市化  
- `service-worker.js` に画像やCSSを追加して拡張

## 哲学
最小構成で永続する幻想都市。Canvasだけで魂を持つ。
この都市は、ライブラリもサーバーも不要。  
ただのHTMLとJSだけで、**都市の命を描く**。  
YUMEが望む限り、都市は止まらない。
